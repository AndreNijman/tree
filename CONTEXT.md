## 1. What this is

`tree` is a **full-progression Terraria clone** written in **plain JavaScript (ES5-era style, no build step, no framework, no dependencies)**. It runs entirely in the browser as static files.

- **Two-phase progression**: the game starts in **pre-hardmode** (copper/silver/gold ore, **one evil biome per world — Corruption OR Crimson, player-selectable at world creation (Random/Corruption/Crimson)** with its matching stone + demonite/crimtane ore + enemies) and transitions to the existing **hardmode** phase (Cobalt → Mythril → Adamantite, mechanical bosses The Twins / The Destroyer / Skeletron Prime, Hallowed gear) once the Wall of Flesh is defeated, all the way through the Moon Lord victory.
- Entire game is **procedurally generated** from a seed (world + tile data). No assets; all art is drawn programmatically on `<canvas>`; all sound is synthesized with WebAudio.
- Open `index.html` directly in a browser (e.g. double-click, or `npx serve` / VS Code Live Server). No server or build needed.

## 2. How to run

1. Open `index.html` in a browser (Chrome/Edge/Firefox).
2. Or run a local static server from the project folder: `npx serve .` then open the printed URL.

Controls (documented in the game's How To Play):
- Move: `A`/`D` or arrows · Jump/glide: `Space`/`W` (multi-jump wings after release) · Run: `Shift`/`Ctrl`
- Mine/Attack: Left click · Place/Interact: Right click · Hotbar: `1`–`0` or scroll
- Inventory/Craft panel: `E` · Guide: `H` · Drop: `Q` · Pause: `Esc` · Save: `Esc` → Save & Quit
- Bosses: craft a Mechanical item, select it, click to summon.

## 4. What main.js must do

This is the intended contract — every other file assumes these exist on a global `game` object. Build `js/main.js` to satisfy ALL of the following:

### 4.1 Game object fields (used across the codebase)
- `game.world` — `new World(W, H, seed)` with `generate()` called; also `world.nearbyStations = []` refreshed each frame (see `findStations` in `world.js:111`, used by crafting).
- `game.player` — `new Player(world)`; call `starterItems()` for a fresh world.
- `game.cam` — `{x, y}` camera (world px), centered on player each frame (smooth lerp is nice).
- `game.entities` — array (players, enemies, bosses, guide, arms).
- `game.projectiles` — `makePool(...)` instance.
- `game.pickups` — array of `{item, count, x, y, seed, t}` (see `addPickup` below).
- `game.fx` — visual effects array; each `{type, x, y, t, max, seed, ...}`. `drawFX` uses `f.t/f.max` so `max` must be set when pushed, or set `f.max` = starting `t`.
- `game.fxTexts` — floating combat text array; each `{x, y, text, t, color}`.
- `game.bossBars` — array of `{id, name, hp, maxHp, color}` (see `makeBoss` in `bosses.js:15`).
- `game.bossesDefeated` — `{}` keyed by `'twins' | 'destroyer' | 'skelprime'` (set in `killBoss`).
- `game.clouds` — array for parallax clouds (render loop reads `game.clouds[i].x/y/w/h/parallax`).
- `game.timeOfDay` — `0..1` (0 = midnight, 0.5 = noon). Advances slowly; drives day/night sky & lighting.
- `game.lightCanvas`, `game.minimap` — lazily created canvases (render.js handles these).
- `game.panelOpen` — bool; when true, player update skips mouse actions and panels show.
- `game.world.dirty` — set `true` after tile changes so minimap can rebuild (see `buildMinimap`).
- `game.hardmode` — bool (false = pre-hardmode). Gates ore gen (`world.generate(game.hardmode)`), enemy pools (`pickEnemy`), soul drops (`dropTable(type, game)`), NPC roster (`spawnNpcs`). Set true by `game.startHardmode()`. `game.world.generate(game.hardmode)` is called at world creation.

### 4.2 Game methods (called from other files — implement ALL)
- `game.message(text)` — show a HUD message (`#message` div, fade out).
- `game.spawnFloatingText(x, y, text, color)` — push into `fxTexts`; decay `f.t`.
- `game.spawnMinePuff(x, y)` — small break particles (push into `fx`).
- `game.addPickup(x, y, id, count)` — push pickup with random `seed`; magnetize to player; auto-add to inventory when close (`Inventory.add`); play `AudioSys.play('pickup')`.
- `game.hitBoss(e, dmg, kbx, kby)` — delegates to `bossHit(e, dmg, kbx, kby, game)`.
- `game.damagePlayer(dmg, from, kbx)` — calls `player.damage(dmg, from, kbx)`.
- `game.flash()` — trigger `#screenflash` opacity flash.
- `game.respawn()` — reset player at spawn, clear dying, restore hp/mana.
- `game.deathscreen()` — show `#deathscreen` overlay.
- `game.spawnBoss(bossId)` — route to the pre-hardmode boss spawns (kingslime/eyeofcthulhu/eaterofworlds/brainofcthulhu/queenbee/skeletron/wallofflesh) or hardmode ones (`spawnTwins(game)` / `spawnDestroyer(game)` / `spawnSkeleton(game)` etc.); also needed by `trySummon` (delay 800ms then call).
- `game.anyBossAlive()` — true if any boss entity alive (`e.boss && !e.dead`).
- `game.onEnemyKilled(e)` — progress hooks (e.g. spawn more / messages). Called by `killEntity`.
- `game.checkBossCompletion()` — after all three `bossesDefeated` are true, show a victory message/state.
- `game.placeSpecial(special)` — for `'workbench' | 'furnace' | 'anvil'`: place the station in an adjacent free tile (like `Player.tryPlace` logic) and return true/false.
- `game.startHardmode()` — flip `game.hardmode` to true, message + roar, `world.startHardmode()` ore injection, kill the guide, re-run `spawnNpcs()` for the hardmode-only NPCs. Triggered from `onBossDefeated('wallofflesh')`.

### 4.3 Loop, input, UI wiring
- `requestAnimationFrame` loop updating: `Time.seconds`/`Time.frame`, `Time.seconds += dt`, world entities (`enemyStep`/`bossStep` per entity), projectiles (`update` fn handles movement + collision vs tiles + enemies + player), pickups, fx/fxTexts decay, player update, camera, day/night, `world.nearbyStations = world.findStations(player.x, player.y)`, HUD, minimap dirty checks.
- Keyboard: fill `KEY` (held) and `KEY_JUST` (pressed-this-frame) from `keydown`/`keyup`. Handle `E` (toggle panel), `H` (guide), `Q` (drop selected), `Esc` (pause/menu), `1`–`0` (hotbar select).
- Mouse: update `MOUSE.x/y` (screen), `MOUSE.wx/wy` (world via camera), `MOUSE.down/right` on `mousedown/up`, `MOUSE.wheel` for hotbar scrolling; `MOUSE.tpx/tpy` (tile-preview for `#tilehint`).
- Menus: `#btn-new` → generate new world (show `#loading` + `#loadprogress` during gen since it's synchronous), hide main menu; `#btn-continue` (currently hidden — save system not implemented) → load save; `#btn-howto` toggles `#howto`; `#btn-respawn` → `respawn()`.
- Panel tabs: switch `.panel-page` visibility; render `#panel-inventory` (50 cells + armor + desc), `#panel-crafting` (categorized recipe grid using `stationsForPlayer`/`recipeAvailable`; click to `craftRecipe`), `#panel-guide`.
- Hotbar: render `#hotbar` (10 slots from `inventory.slots[0..9]`) + selection highlight + counts.
- HUD each frame: `#clock` (from `timeOfDay`), `#depth`, `#biome`, `#fps`, `#hpbar`/`#manabar` widths, `#bossbars` from `game.bossBars`, `#crosshair` position, `#interact` prompts, `#message`.
- Resize: set canvas size to window; `canvas.width/height` must match CSS for correct drawing.
- Call `AudioSys.init()` on first user gesture (browser autoplay policy) and `AudioSys.resume()` on resume.

### 4.4 Spawning / world lifecycle
- Spawn a `Guide` entity at `world.guidePos` (type `E.GUIDE`).
- Ambient enemy spawning near the player per biome/depth — **pre-hardmode** (`!game.hardmode`) = weak pools (slimes, zombies, demon eyes, cave bats, goblins, jungle/snow/corrupt/crimson critters); **hardmode** = hard enemies like Armored Zombie, Wraith, Pixie, Unicorn, Chaos Elemental, Gastropod, Wyvern at sky depth, etc. — see `ENT_DEF`). Corrupt/Hallow enemies in their biomes; night spawns during night.
- Fall-out-of-world handling: `player.update` already calls `die()` when too low (`player.js:132`).

## 5. Conventions

- **Style:** ES5 — `var`, `function` constructors + `Prototype.method = function(){}`, no `let`/`const`/classes/arrow functions. **Follow this.** Global constants uppercase; global state lowercase.
- **Globals are shared intentionally** (no modules, single script scope). Don't shadow them.
- **Units:** positions/sizes in pixels; tiles are `TILE`=16px. Entity `x,y` = **center**; player `x,y` = center, `h` spans up from feet (see `physicsStep` in `entities.js:3`).
- **Timing:** most updates use `1/60` per-frame constants (assumes 60fps) — match that in main.js (fixed-ish timestep or scale by `util.delta()`).
- **No comments unless needed** (existing code is lightly commented, mostly section headers).
- **No external libs.** Procedural everything.
- `Math.random()` is used freely at runtime (only world gen needs `mulberry32` determinism from seed).
