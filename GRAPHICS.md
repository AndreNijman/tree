# Pixel-art graphics pass

Graphics work log. The baseline through lava creatures was committed/deployed in `b795929`; `1038499` refreshed stale gameplay cache tags. The segmented-creature, sky/sand, single-body flyer, aquatic, ground-crawler, melee-goblin, ranged-goblin, pirate, Frost Legion, Martian infantry, Martian heavy-unit, Martian specialist, Pumpkin Moon, Frost Moon infantry, Frost Moon heavy/flyer, Present Mimic and Solar Eclipse base batches are included in the October 28 release below. ## Implementation

- `js/pixelart.js`: original artwork factories, neighbor-aware terrain variants, live-tree validation, sprite palettes, and caches. No world/inventory/progression writes.
- `js/combatart.js`: bounded original boss/projectile/weapon/arena/troop/general-enemy sprite cache and presentation-only combat draw hooks. All share the 256-entry cache. It is loaded after the base artwork module; unsupported cases explicitly fall back to the retained renderer.
- Its segmented-enemy hook runs before the renderer's head-only cull, rejecting bosses, summons and Etherian flags. It culls each live head/body/tail independently, so a visible part is not dropped because its head is outside the viewport. The last array record supplies tail identity; dead records are omitted without moving other parts or inventing bridge pieces. Integer nearest-neighbor heading rasters share the same bounded cache; drawing never writes segment coordinates, facing or network interpolation samples.
- `js/render.js`: artwork integration, surface foliage tinting, backgrounds, common actors, and light compositing. The combat hook now runs before the separate Etherian-boss branch; the original Old One's Army drawings remain intact for before/after comparisons and unsupported cases.
- `js/oldonesarmy.js`: read-only world/sentry/troop artwork hooks, retaining legacy drawings. The renderer's pre-existing duplicate arena pass was removed; its unrelated duplicate heart-crystal pass is unchanged. Lightning Aura culling includes the decorative field when the device is just offscreen. Troop AI, stats, damage, objectives and rewards are unchanged by the troop batch.
- `js/main.js`: pixel icon presentation and station-recipe artwork only; existing gameplay/audit patches are preserved.
- `css/style.css`, `assets/pixel-heart.svg`, `assets/pixel-star.svg`: in-game chrome and original HUD artwork. Title/settings layouts are retained.
- `index.html`: loads both artwork modules after the renderer's shared color helpers and before game initialization.

No Terraria assets were downloaded or copied. The artwork batches above did not change save formats, network protocols, physics, item acquisition, or world generation. The separately requested controls/combat follow-up below intentionally changes hit detection and adds mining assist.
